# 06: 查看流程时，追踪高亮与详情保持一致

**What to build:** 使用者在生成的图中悬停、点击或清除焦点时，能看清真实上下游执行链。节点、路径、箭头和标签同步变化，约束与资源保持上下文角色，所有相关内容仍能点击检查来源与理由。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 焦点按执行关系追踪祖先与后代，不因共享祖先而点亮无关同级分支；循环图安全终止。
- [ ] 复用已正确的方向敏感追踪计算，修复呈现联动，不另起遍历算法重写。
- [ ] 节点、SVG 路径、箭头和独立标签采用一致的焦点状态；不存在边已置灰但标签仍保持高亮的状态。
- [ ] 未命中的约束与资源上下文连同关联线、箭头、标签一致置灰，不因端点碰到焦点就伪装为执行链；它们仍可点击查看详情。
- [ ] 点击节点、边或边标签能查看对应对象的证据及必要理由；改变追踪状态不破坏既有点击行为。
- [ ] 悬停优先于节点选中，移开后恢复选中对象的追踪；关闭详情或点击空白恢复全图。
- [ ] 使用含同级分支、循环及资源或约束关联的实际生成图，在指定的现有 CDP Chrome 中验证交互和视觉状态；不新增浏览器测试框架，不关闭共享 Chrome。
