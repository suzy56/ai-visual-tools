# 08: 安装后的 skill 对多类原文完成一致交付

**What to build:** 使用者调用安装后的 skill，可以对不同类型原文稳定完成正式解释、按需建议及随包保守预览。技能指令、参考材料、通用构建与安装版本一致；一次正式交付包含可复核的源快照、语义图、覆盖记录和实际打开验证的 HTML，而不是只有开发目录中的演示结果。

**Blocked by:** 03: 按语义阶段解释，并交付可核对的覆盖记录；04: 随包 Markdown 预览不凭清单格式制造分支；05: 明确要求优化时，另交付工程建议；06: 查看流程时，追踪高亮与详情保持一致；07: 长标题、分支与回路下，生成的图仍可读。

**Status:** ready-for-agent

- [ ] 安装后的正式调用走完整原文理解、语义提取、覆盖和逐边审查、固定渲染与交付流程；每个执行步骤有可核对的完成条件。
- [ ] 技能主文保留模式选择、步骤和硬约束；详细规则和正反例按需读取，三类语义及语义阶段复用权威术语，不在多处散落重新定义。
- [ ] 正式交付包含同一版本的源快照及 SHA-256、已审计语义图、覆盖记录和实际检查的 HTML；只有明确要求时另附工程建议。
- [ ] 标题、作者、来源和示例输出属于当前主题；当前主题没有示例输出时不展示其他技能的结果。说明性示例不被声称为真实业务执行或成功产物。
- [ ] 从实际安装入口验证备份、插件开发、调试和替代操作等不同原文；保留权限、否定要求、跳过条件、条件迭代和人工复核，不引入固定节点配额或通用成功终点。
- [ ] 正式 Agent 解释与随包 Markdown 保守预览的能力区别清晰，两个入口均使用相应已验证版本，不混用过期模板。
- [ ] 源码修复经过各票自身验证后统一构建，同步包内模板与安装技能；渲染器在处理新输入前后保持一致，不为新主题修改代码或生成文件。
- [ ] 交付 HTML 的核心查看行为无需开发服务器或模型 API 密钥；渲染错误明确失败，不覆写输入，不执行业务脚本。
- [ ] 使用原有公共 Interface 和指定的现有 CDP Chrome 完成跨主题交付检查，记录实际结果与未通过项，不以构建成功或结构校验代替整体验收。
- [ ] 本票验证安装后的完整交付，不代替前置各票的针对性回归与页面检查；没有遗留未完成的必要行为时才算完成。
