# 07: 长标题、分支与回路下，生成的图仍可读

**What to build:** 不同 skill 通过同一渲染器生成图后，长标题、长标签、普通分支、回流和自回环仍能阅读和辨认。使用者可以平移、缩放、适配视图和全屏查看，不依赖临时缩写、手改坐标或某个输入的专用页面。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 连线标签以实际路由曲线的正确位置为起点，结合实际节点和标签边界处理碰撞，不只使用端点算术中点。
- [ ] 在验收输入中，标签不遮挡节点或彼此覆盖；既有默认样例中跳过路径遮挡理解阶段、普通关系与约束标签重叠的问题均消失。
- [ ] 实际换行后的长标题被卡片和布局容纳，不覆盖相邻卡片；卡片简短摘要与详情完整性并存。
- [ ] 回流和自回环的路线与标签不穿过中间卡片，箭头方向和目标明确；同一套规则适用于不同输入。
- [ ] 平移、缩放、适配视图和全屏后几何关系仍正确；不能仅以文字不可读的全图缩略图证明布局可用。
- [ ] 修复不按特定标签文案、固定节点数或单个案例特判，不单独修改生成 HTML 或手填节点坐标。
- [ ] 使用长标题、长标签及多种分支和回路的实际生成图，在指定的现有 CDP Chrome 中记录可读性与几何检查；不为内部布局细节建立永久测试。
