# 01: 完整保留原文、阶段正文与资源

**What to build:** 使用者输入一个含子步骤、权限条件和资源引用的 skill 后，生成结果可以查看完整原文和各语义阶段的完整详情，资源归属正确。源快照及 SHA-256 对应同一输入版本；文件导入、渲染和图数据导出不使内容丢失。复用已有输入和查看入口，不建设新的语义服务。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 保存原始输入的完整源快照及 SHA-256，来源页展示对应原文，而不是用解析后的图 JSON 代替。
- [ ] 明确步骤下的段落、嵌套清单、权限要求、条件和必要上下文归入所属阶段；卡片可以摘要，详情必须保留完整必要内容。
- [ ] 阶段引用的脚本、政策和其他资源可以找到，且关联到正确阶段；共享资源保持共享，不把每次引用变成不同文件。
- [ ] 未核实的资源路径明确标记为未核实，不声称资源存在、执行过或验证成功。
- [ ] frontmatter、阶段正文和证据范围与保留的源文一致；导出再导入后，源文、详情和来源信息不丢失。
- [ ] 文件导入与现有渲染命令产生的 HTML 均可实际查看上述内容；解析及渲染不覆写输入，也不执行文档里的业务命令。
- [ ] 使用包含权限限定、嵌套步骤和共享资源的备份输入，证明旧行为中的丢失被修复；回归断言内容及归属，不只断言子清单没有变成额外节点。
